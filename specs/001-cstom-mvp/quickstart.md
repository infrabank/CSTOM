# Quickstart: CSTOM MVP Core

**Goal**: Validate the MVP workflow end-to-end with a single contract.

## Scenario: Single Contract Pilot

1. Create a Contract with scope, status, and risk flags.
2. Add a Task and record a Decision Log explaining the rationale.
3. Register a Change/Incident and link it to a related event if applicable.
4. Generate a Monthly Report and verify counts and Decision Log references.
5. Verify RBAC restrictions (PM edit, engineer action, customer read-only).

## Expected Outputs

- Contract record with status history and risk flags.
- Task record with Decision Logs attached.
- Change/Incident record with timestamps and links.
- Monthly report including counts and summary.
- Audit events for each write operation.
